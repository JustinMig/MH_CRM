# M&H CRM

Standalone CRM framework for M&H Insurance Group.

- New CRM target: `MH.mayerig.com`
- Existing CRM remains: `crm.mayerig.com`
- No fake clients or sample CRM records are included.
- Database, authentication, storage, RingCentral, and App Store packaging are intentionally disconnected in this framework build.

## Framework modules

Dashboard, Clients, Client Information, Appointments, Communications, Notifications, Documents, Medicare, Life, Retirement, Agents & Admin, and Settings.

## Isolation

Deploy this repository as its own Vercel project. Do **not** connect it to the existing `Mayer-insurance-crm` Vercel project or GitHub repository.
